# Italy Travel Map Prototype

Mobile-first Italy travel planning prototype with:

- Leaflet + OpenStreetMap interactive maps
- City and attraction markers
- Local attraction images
- Official links, Google Maps links, transit route links
- Saved spots and itinerary state in browser localStorage

## GitHub Pages

Publish from the repository root on the default branch.

If using GitHub Pages manually:

1. Open repository Settings.
2. Go to Pages.
3. Set source to Deploy from a branch.
4. Select the default branch and `/root`.
